## Computational Materials Science

A collection of atomistic simulation projects exploring how materials behave at the molecular and electronic scale.

The work covers **Molecular Dynamics**, **Monte Carlo methods**, **nanoparticle melting**, **crystal defects**, and an introduction to **Density Functional Theory**.

### Tools used

- LAMMPS for atomistic simulations
- Quantum ESPRESSO for DFT calculations
- OVITO for visualization
- Python for analysis and plots

Each project includes its simulation files, results, visualizations, and a short scientific report. The complete code and reports are available through the repository link below.
