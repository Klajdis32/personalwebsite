## Chat Interface for Llama

A responsive web chat interface built with **React** for interacting with Meta's **Llama 3.3 70B** model.

The React frontend sends messages to a small backend API, which connects to the model through **Groq** and returns responses in real time.

### Main features

- Clean conversational interface
- Fast model responses through the Groq API
- Separate React client and backend service
- Environment-based API key configuration

This project was an experiment in combining a modern frontend with a hosted large language model. The full source code is available through the repository link below.
