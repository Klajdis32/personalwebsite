## Full-Stack Authentication System

A complete authentication application built with **React**, **Express.js**, and **MySQL**.

Users can create an account, sign in securely, verify their email, and reset a forgotten password. The application also includes role-based access and a separate administration interface.

### Main features

- Secure login and registration
- Email verification and password reset
- User and administrator roles
- Session handling and protected routes
- Separate client, API, and admin applications
