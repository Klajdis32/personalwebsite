## Arduino Temperature Meter

A simple temperature meter built with an **Arduino Uno**, an **LM35 sensor**, and a **16×2 LCD display**.

The Arduino reads the sensor voltage, converts it to degrees Celsius, and refreshes the temperature on the screen every half second. It is a compact beginner project for learning how analog sensors and LCD displays work together.

### Wiring

The LM35 output connects to analog pin **A0**, while the LCD uses Arduino digital pins **12, 11, 5, 4, 3, and 2**.
